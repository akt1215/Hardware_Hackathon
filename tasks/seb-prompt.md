Build firmware for an "Air Theremin" on the STM32 Nucleo-G474RE using the PlatformIO
Arduino framework already configured in this repo (`platformio.ini`, env `nucleo_g474re`).
Implement against the spec in `tasks/todo.md` — read it first and follow the pin map,
behavior spec, and acceptance criteria exactly.

Hardware and pin map (Arduino pin names):
- I2C bus on D14 (SDA) / D15 (SCL): MPU-6050 @ 0x68, MCP9808 @ 0x18.
- HC-SR04: TRIG = D7, ECHO = D6 (ECHO is level-shifted via a 1k/2k divider — assume 3.3V-safe).
- STEMMA speaker signal on D9 (PWM/timer pin, use tone()).
- Status/VU LED on LED_BUILTIN (PA5, use analogWrite for brightness).

Behavior:
- HC-SR04 distance (~4–40 cm) -> pitch, quantized to a pentatonic scale across ~2 octaves.
  Out-of-range -> note-off (silence + LED off). Apply an EMA filter (alpha ~0.3) to distance.
- MPU-6050 roll angle (±~30°) -> pitch bend / vibrato on the current note. A sharp accel
  spike re-triggers the note.
- MCP9808 temperature -> scale select: below ~24°C minor pentatonic, at/above major pentatonic.
- LED brightness tracks pitch height; off when silent.
- Serial @ 115200 prints dist_cm, roll_deg, temp_c, note, freq_hz every loop for tuning.

Engineering requirements:
- Structure cleanly: separate small modules for the IMU, ultrasonic, temperature, audio,
  and LED, with a thin main loop running ~30 Hz. Keep it simple — minimal, readable code.
- Use the Adafruit MPU6050 and MCP9808 Arduino libraries (add to lib_deps if not present).
- Handle sensor init failure gracefully: log over serial and keep the loop running rather
  than hanging the I2C bus.
- Build must pass `pio run` with no errors. Do not add code that isn't needed for the spec.
- Implement in the layer order from tasks/todo.md (L1 IMU -> L2 ultrasonic -> L3 audio MVP
  -> L4 expression -> L5 scale select). Make the L3 audio MVP work end-to-end first, then layer on.
