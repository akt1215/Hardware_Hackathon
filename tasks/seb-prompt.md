# Seb Prompt — Particle Storm remote firmware

Paste the block below into `seb chat` (or launch an agent with it). First connect the Hideout
project to this repo and add the STM32G4 / MPU-6050 / HC-SR04 / MCP9808 / STEMMA Speaker

A complete, working reference firmware already exists at `src/main.cpp` and builds with

---

Harden and extend the STM32 Nucleo-G474RE firmware in `src/main.cpp` (PlatformIO Arduino
framework, env `nucleo_g474re`). It is a physical motion remote for a browser particle storm:
read sensors and stream one CSV line per frame over USB serial. Read `tasks/todo.md` first and
match the serial protocol, pin map, and acceptance criteria exactly.

Serial protocol (115200 baud, one line per frame, '\n'-terminated):
    roll,pitch,dist,temp,gesture
- roll/pitch: float degrees from MPU-6050 accel (roll = atan2(ay,az), pitch = atan2(-ax,hypot(ay,az))).
- dist: float cm from HC-SR04, EMA-smoothed, -1 when out of range (>60cm or no echo).
- temp: float degC from MCP9808.
- gesture: int, 1 on a shake (accel magnitude deviates from 1g beyond threshold) with a cooldown, else 0.

Pin map (Arduino names): I2C D14(SDA)/D15(SCL) — MPU-6050 @0x68, MCP9808 @0x18.
HC-SR04 TRIG=D7, ECHO=D6 (3.3V-safe via 1k/2k divider). Speaker on D9 (tone()). LED on LED_BUILTIN.
Serial goes out USART2 -> ST-Link Virtual COM Port (the browser's Web Serial channel).

Requirements:
- Stream at ~50 Hz without blocking; keep the HC-SR04 pulseIn timeout short (~25ms) so it
  doesn't stall the stream when no hand is present.
- Speaker: ready-beep on boot, short whoosh on each shake/explode.
- Handle sensor init failure gracefully: print a line starting with '#' (so the web parser
  ignores it) and keep streaming the sensors that did initialize.
- Use the Adafruit MPU6050 and Adafruit MCP9808 libraries (already in lib_deps).
- Keep it simple and modular (small functions per sensor); no code that isn't needed for the spec.
- `pio run` must pass with no errors. Implement in the layer order in tasks/todo.md and update
  its checklist + Review section as you complete each layer.
